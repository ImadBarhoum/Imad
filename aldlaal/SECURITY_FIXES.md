# إصلاحات الـ API (الدلال)

## خطوات الرفع على السيرفر (بالترتيب)

1. **خذ نسخة احتياطية** من قاعدة البيانات ومن مجلد `api` الحالي.
2. **نفّذ ملف الترحيل على قاعدة البيانات أولاً:**
   `api/database/migrations/001_password_hashes_and_reports.sql`
   - يوسّع عمود `pwd` إلى 255 حرفاً. **إذا رفعت الكود قبل هذه الخطوة سيبقى تسجيل الدخول يعمل، لكن الحسابات الجديدة وتغيير كلمات المرور لن تعمل.**
   - ينشئ جدول `reports` إذا لم يكن موجوداً.
   - إذا لم يكن عمود `video` موجوداً في جدول `properties` فأزل علامة التعليق عن السطر الأخير ونفّذه.
3. **حدّث ملف `config.php` على السيرفر** وأضف المتغيرات الجديدة (انظر `config.example.php`):
   - `$smtp_host`, `$smtp_user`, `$smtp_pass`: إعدادات البريد التي كانت مكتوبة داخل `services/mailer.php`.
   - `$twilio_sid`, `$twilio_token`, `$twilio_from`: بيانات Twilio التي كانت داخل `services/mailer.php`.
   - `$cron_key`: كلمة سرية للمهمة المجدولة (اختياري). إذا عيّنتها فغيّر رابط الـ cron إلى `/cron/autorun/<cron_key>`.
4. ارفع ملفات مجلد `api` الجديدة (بدون استبدال `config.php` و`vendor/`).
5. جرّب تسجيل الدخول بحساب مدير وحساب مستخدم.

## كلمات المرور
- أصبحت كلمات المرور تُحفظ مشفّرة (`password_hash`).
- كلمات المرور القديمة تعمل كما هي، وتُشفَّر تلقائياً عند أول تسجيل دخول ناجح لصاحبها.
- **غيّر كلمات مرور المدراء الضعيفة** (مثل `123456`) من لوحة التحكم.

## مفاتيح يجب تغييرها (لأنها كانت داخل الملف المضغوط)
- مفتاح Firebase Service Account (من Google Cloud Console أنشئ مفتاحاً جديداً واحذف القديم).
- كلمة مرور البريد `noreply` وبيانات Twilio وخدمة SMS ومفتاح بوت تيليغرام.
- `$secret_key` الخاص بالـ JWT (تغييره يسجّل خروج جميع المستخدمين).

## ما الذي تم إصلاحه
| المشكلة | الخطورة | الإصلاح |
|---|---|---|
| أي مكتب يستطيع تعديل إعلان أي مكتب آخر والاستيلاء عليه (`agency/properties/edit`) | حرجة | التحقق من أن الإعلان يخص المكتب نفسه |
| حقن SQL عبر `per_page` / `page` في عدة ملفات | حرجة | تحويلها لأرقام صحيحة (`int_param`) |
| حقن SQL عبر `location` و`imgs` و`search_json` (JSON بدون تهريب) | حرجة | تهريب القيم قبل الاستعلام |
| كلمات المرور محفوظة كنص عادي | عالية | `password_hash` / `password_verify` مع ترحيل تلقائي |
| بيانات SMTP وTwilio مكتوبة داخل الكود | عالية | نُقلت إلى `config.php` |
| `img/save` يقبل مسارات ملفات وروابط (قراءة ملفات السيرفر / SSRF) | عالية | قبول صور `data:image/...;base64` فقط |
| رفع الفيديو بدون تسجيل دخول | متوسطة | يتطلب تسجيل الدخول |
| توكن المدير يعمل على مسارات المستخدم والمكتب | متوسطة | مسارات `user` و`agency` لتوكن المستخدم فقط |
| XSS في صفحة مشاركة الإعلان `link/<id>` | متوسطة | تهريب HTML |
| رمز OTP وتوكنات الدخول تستخدم `rand()` | متوسطة | `random_int()` |
| تشغيل ملفات PHP داخل `uploads` | متوسطة | ملف `uploads/.htaccess` يمنع ذلك |
| `force_logout` لا يسجّل خروج المستخدمين (اسم عمود خاطئ) | خطأ | `login_token` |
| `cron` يرسل بيانات الإعلان الخطأ في الإشعار (`$qr` بدل `$ads_qr`) | خطأ | تم الإصلاح |
| `alerts/reset_count` لا يعمل (فرع مكرر `remove`) | خطأ | تم الإصلاح |
| المفضلة: الصفحة الثانية وما بعدها لا تعمل، وأخطاء عند حذف إعلان مفضل | خطأ | ترقيم صحيح |
| التقييم يقبل أي رقم (مثلاً 999) | خطأ | محصور بين 1 و5 |
| `get_citys` يتجاهل الدولة (أولوية `or`) | خطأ | أقواس |
| الاتصال بقاعدة البيانات `utf8` بدل `utf8mb4` (الإيموجي) | خطأ | `utf8mb4` |
| Twilio بدون تحقق من شهادة SSL | منخفضة | تفعيل التحقق |

## ملاحظات لم أغيّرها (تحتاج قرارك)
- الأرقام التجريبية في `send_phone_otp` (`962777777777`...) لا يمكنها الدخول: المتغير `$code = "223344"` لا يُستخدم. إذا كانت لمراجعة متجر التطبيقات فيجب تغييره إلى `$otp`.
- تعديل إعلان منشور لا يعيده إلى المراجعة (`admin_review`)، فيمكن للمكتب تغيير محتواه بعد الموافقة.
